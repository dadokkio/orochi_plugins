# orochi_plugins

Curated catalog of Volatility 3 plugins for [Orochi](https://github.com/LDO-CERT/orochi). Custom plugins maintained in this repository are documented in [plugins/README.md](plugins/README.md).

> **Note:** All packaged `.zip` plugins in this repository have been reviewed and tested for compatibility with **Volatility 3 `2.28.3`**.

## Compatibility Matrix

| Orochi Version | Volatility 3 | Python | Compatible `orochi_plugins` Ref | Notes |
| --- | --- | --- | --- | --- |
| `>= 2.7.0` (`new` / `master`) | `2.28.3` | `3.13 – 3.15` | `main` (all 33 `.zip` packages) | Updated for Vol3 `2.28.3` APIs (`ModuleRequirement`, `PsList 3.x`, `FileScan 2.x`, `HiveList 2.x`, `linux.utilities.modules 3.x`) |
| `<= 2.6.x` (legacy) | `2.0 – 2.7` | `3.9 – 3.12` | Commit `91d7967` (8 legacy `.zip` packages) | Uses legacy `TranslationLayerRequirement` / `SymbolTableRequirement` and `PsList 2.x` |

**Platform notes:**
- `clipboard.zip`, `messagehooks.zip`, `screenshot.zip`: require **Windows x64** (Volatility 3 `windows.windowstations` only supports x64 GUI symbols).
- `pehash.zip`: includes `run.sh` to install `libfuzzy-dev` / `libffi-dev` via `apt` inside Orochi containers.
